JawnTide

A Red PvP Asheron’s Call ACE Emu forked from DocTide. Thanks to Doctor Zaius, Spacemonkey, and other contributors leading up to this release.

play.jawntide.comport 9000

How to connect

  1. Install Asheron’s Call. You need the end-of-retail client. The ACEmulator guide at emulator.ac walks you through the installer and patch.
  2. Install ThwargLauncher from thwargle.com. It starts the game and logs you in.
  3. Add JawnTide as a server. Name it JawnTide, set the address to play.jawntide.com, port 9000, emulator type ACE.
  4. Pick an account name and password. Your account is created the first time you log in with them.

The Server

PvP
Everyone is a player killer. Die to another player and you turn white for a short while before you’re red again.
Current stage
Stage 1: loot up to tier 6, level cap 126. Later stages raise the loot tier and the cap.
Accounts
Up to 2 accounts logged in at a time per person.
Connections
No VPNs or proxies.
