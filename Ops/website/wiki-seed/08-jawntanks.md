# JawnTanks
JawnTanks is JawnTide's browser tank game. It runs in any modern browser, no install needed. Find it in the site menu.

## Playing
- Pick a name, then make a room or join one from the lobby.
- Modes: free-for-all and 2v2.
- The room host starts the match. Use the invite button to copy a link for friends.
- Rooms have chat.

## Tips
- Shots bounce off walls. Use the angles.
