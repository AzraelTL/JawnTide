# Editing the wiki
Anyone can read the wiki. Editing is for **contributors**: staff pick one character per player who can edit. Want to help? Ask on Discord. Every save is kept in the page history, so mistakes can be undone.

## Getting an account
1. Once staff have made your character a contributor, go to [link your game account](/wiki/link) and get a code.
2. Log in to JawnTide with your contributor character and type `/wiki CODE` in chat.
3. Back on the website, pick a wiki password. You sign in with your character name and that password.

Forgot your password? Do the same steps again to set a new one.

## Writing
| You type | You get |
|---|---|
| `## Heading` | A section heading (`###` for a smaller one) |
| `**bold**` and `*italic*` | **bold** and *italic* |
| Backticks around a word | `code` |
| `- item` | A bullet list (`1.` for numbered) |
| `[[World bosses]]` | A link to another wiki page |
| `[[World bosses\|the bosses]]` | The same link with your own text |
| `[text](https://example.com)` | A link to another site |
| `> text` | A note box |
| `\| a \| b \|` | Table rows (a `\|---\|---\|` line after the first row makes it a header) |

## House rules
- Write about JawnTide's custom content: bosses, events, Town Control, arena, quests, loot.
- Stick to what's true on JawnTide. If something changed, fix the page.
- No personal attacks or spoilers that ruin a live event.
- Staff can revert edits, lock pages and block accounts.
