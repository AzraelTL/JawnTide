# Loot stages
JawnTide opens loot up in stages. The current stage is on the [home page](/).

| Stage | Random loot | Level cap |
|---|---|---|
| 1 (launch) | Tier 6, Majors at most | 126 |
| 2 | Tier 7: Epics, no ratings | raised |
| 3 | Tier 8: Legendaries, no ratings | raised |
| 4 | Tier 8: Legendaries with ratings | raised |
| Later | No cap | raised |

> Some content is closed until later stages. Watch Discord for stage announcements.
