# Allegiance Mule + market from in game

**New: Allegiance Mule**
- The Town Treasurers now sell the Allegiance Mule for 1,500 PK Trophies.
- Hang it on a mansion hook and use it to bring out a mule that holds 5,000 items.
- Who can use it is set separately from your storage chests.
- Owners set who else can: /amule storage add NAME, /amule storage remove NAME, /amule storage remove -all, /amule storage allegiance on|off, /amule storage list
- /mule search, /mule page and /mule comps work on it, and so do the page buttons.
- It can't be taken down while anything is stored in it. If the mansion is abandoned, the mule stays with the mansion, contents and all, and the next owner starts with an empty permission list.

**New: list items on the market from in game**
- ID an item in your open My Mule, then type /market 5 mmd, /market 500 pkt, or /market 5 mmd 500 pkt.
- It's a fixed-price listing for 30 days, the same as the website's List button. Auctions are still set up on the website.

**My Mule**
- Mules now only work for players standing on the same landblock as the mule.

**Target Drudges**
- Players no longer see the drudges' stats and buffs when they recall in or ID one. Damage reports are unchanged.
- Fixed drudges sometimes losing their setup.

**Fix: Assassin's Roost**
- The Bottle in Holtburg is back, so the quest can be completed again.
