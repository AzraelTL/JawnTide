**My Mule**
- Page buttons: when your mule holds more than one page, the list starts with >> Next page and << Previous page entries. "Buy" one to turn the page (nothing comes out of the mule). /mule page N still works too.
- /mule comps on: shows only spell components (tapers, scarabs...) in one short list, so restocking metas always find them. /mule comps off (or reopening the mule) shows everything again.
- /mule search now also finds items by name, e.g. /mule search shield.

**Suit Builder (website)**
- Shirts and pants are now used together (most shirts were wrongly treated as clashing with pants).
- Every slot you tick gets filled when you own something for it, and empty slots say why.
- Each spell you ask for is now looked for properly, so suits no longer end up with 3 of one cantrip and another missing; searches can run up to 20 seconds on big mules.
- Item search has an Underclothes type.

**Target Drudges**
- Every Target Drudge now uses the same setup, and it no longer resets when its area reloads. Damage you test on them is consistent from now on.
